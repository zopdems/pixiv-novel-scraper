# Pixiv 小说自动抓取器（Pixiv Novel Scraper）

自动追踪你关注的 Pixiv 作者，把他们的新小说抓取为**带封面的 EPUB 电子书**，并维护一份 **Markdown 索引**。Windows 桌面程序，便携设计，所有数据保存在程序目录内，不写 C 盘。

> 它不是「下载器」，而是「追更器」：作者改名、作品更新、作品删除、账号注销，本地书库都能感知并同步。

## 功能特性

- **📚 EPUB 输出**：封面首页（无封面时自动用正文第一张插图）、作品信息页（作者 / 发布时间 / 标签 / 可点击的原作链接）、正文标记完整转换（`[chapter:]` 分页、`[[rb:]]` 注音、`[pixivimage:]` 插图、`[jump:]` 跳转链接）
- **🔄 增量追更**：新作品水位线 + 系列构成轮询，远端内容更新自动重新打包，失败队列优先重试
- **🖼 插画/漫画追更**：独立的「插画作者」名单，加入即追更，与小说名单互不干扰（同一作者可同时入两个名单）；与小说共用同一套增量逻辑，单页作品存为 `标题.ID.png`，多页作品存为独立文件夹；同样支持更新检测、删除标记、R-18 与标签黑名单过滤
- **🗂 Markdown 索引**：小说与插画各自独立成文（`作者ID_昵称.md` / `作者ID_昵称_插画.md`），含作者主页链接、收录统计、最近抓取摘要，远端删除的作品自动标注
- **🔐 登录方式**：Cookie 粘贴导入，或内置浏览器登录自动获取；Cookie 经 Windows DPAPI 加密存储，日志自动脱敏
- **🛡 稳健抓取**：Chrome TLS 指纹模拟（过 Cloudflare）、请求限速、指数退避、连续失败自动暂停、磁盘余量保险丝、任务可手动中止
- **👤 作者管理**：小说 / 插画双名单独立维护，批量导入、启停开关、离线待校验、作者改名自动迁移目录与索引、账号注销自动识别停用
- **🔍 本地检索**：按标题 / 作者 / 标签检索已收录作品，双击直达文件
- **🎒 便携与迁移**：数据全在程序目录 `data\` 下；一键导出 / 导入备份 JSON（含作者、设置、Cookie），换电脑无损搬家
- **⏰ 挂机友好**：系统托盘常驻、每日定时抓取、可选开机自启（静默启动，不弹主窗口，直接驻留托盘）
- **⚙️ 32 项高级设置**：覆盖「触发与筛选 / 文件输出 / 内容编排 / 更新与去重」四个环节，可开关可调参，默认值全部等价于原有行为，支持一键恢复默认（详见 [高级设置说明](SETTINGS.md)）

## 界面预览

主界面采用「顶栏 + 左侧导航 + 卡片式内容区」布局，包含四个页面：

- **作者**：小说作者 / 插画作者双名单，支持批量导入、启停开关，双击昵称直达 Pixiv 主页
- **任务**：手动触发同步，深色终端样式的实时日志，失败 / 远端已删除队列
- **检索**：按标题 / 作者 / 标签搜索本地书库，双击打开所在目录
- **设置**：外观主题、存储路径、抓取策略、文件输出、内容编排、更新策略、网络、登录 Cookie、备份迁移；右上角可一键恢复高级设置默认值

支持**浅色 / 深色双主题**，可在「设置 → 外观」切换，或点击右上角月亮 / 太阳图标快速切换，选择会随配置保存。

## 安装与使用

### 方式一：安装包（推荐给普通用户）

1. 下载 `PixivNovelScraper-Setup-v1.4.3.exe`（若杀软误报，改用 `PixivNovelScraper-Setup-v1.4.3-onedir.exe` 目录版）
2. 运行安装包，**可自选安装位置**（无需管理员权限）
3. 首次启动按四步引导完成配置：选目录 → 导入 Cookie → 添加作者 → 风险确认
4. 到「任务」页点「立即抓取」

### 方式二：从源码运行（适合开发者）

```bash
pip install -r requirements.txt
python run.py
```

要求 Python 3.10+。运行自检：`python tests\smoke_test.py`。详细的小白向步骤见[复现运行指南](小白复现运行指南.md)。

### 自行打包

```bash
# 方式 A：单文件 exe（产物 dist\PixivNovelScraper.exe，约 50 MB）
python -m PyInstaller --noconfirm PixivNovelScraper.spec

# 方式 B：目录版（产物 dist\PixivNovelScraper-OneDir\，杀软误报率通常更低）
python -m PyInstaller --noconfirm PixivNovelScraper-onedir.spec

# 安装包（需 NSIS；已安装可直接用 "C:\Program Files (x86)\NSIS\makensis.exe"）

# 单文件版安装包 → dist\PixivNovelScraper-Setup-vX.Y.Z.exe
makensis.exe installer.nsi

# 目录版安装包 → dist\PixivNovelScraper-Setup-vX.Y.Z-onedir.exe（误报率通常更低）
python -m PyInstaller --noconfirm PixivNovelScraper-onedir.spec
makensis.exe installer-onedir.nsi
```

> 安装前请先修改两个 nsi 脚本里的版本号，与本次发布保持一致。
>
> **打包目录版前务必确认 `dist\PixivNovelScraper-OneDir\` 下没有 `data` 子文件夹**——本地运行过 exe 会生成它，里面是你的配置、索引库和日志，`File /r` 会把它一起打进安装包。发现就先删掉再打包。

## 获取 Cookie 的两种方式

1. **浏览器登录获取（推荐）**：软件内点击按钮，在弹出窗口登录 Pixiv，自动提取
2. **手动粘贴**：浏览器登录 pixiv.net → `F12` → 网络/Network → `F5` 刷新 → 点第一个请求 → 标头中复制 `PHPSESSID=` 开头的整段

## 常见问题

| 问题 | 解决 |
| --- | --- |
| 测试连接超时 `curl:(28)` | 启动代理软件，或在设置中手动填写代理地址（如 `http://127.0.0.1:7890`） |
| 提示 Cloudflare 风控拦截 | 请求过密的临时限制，调大请求间隔（建议 3 秒），稍后重试，失败作品会自动重试 |
| Cookie 无效 / 401 | Cookie 复制不完整或已过期，重新登录获取 |
| 改过的设置运行中生效吗 | 请求间隔、命名规则、黑名单等立即生效；Cookie / 代理 / UA 需下轮任务生效 |
| exe 被杀软报毒 | PyInstaller 打包的已知误报（无签名 + 自解压 stub + curl_cffi），可改用**目录版**打包、向厂商提交误报、或加白名单 / 改用源码运行 |

## 目录结构

```
pixiv-novel-scraper/
├── run.py                       # 程序入口
├── requirements.txt             # 依赖清单
├── SETTINGS.md                  # 32 项高级设置说明（作用 / 取值范围 / 相互影响）
├── installer.nsi                # NSIS 安装包脚本
├── PixivNovelScraper.spec       # 打包配置：单文件版
├── PixivNovelScraper-onedir.spec# 打包配置：目录版（误报率更低）
├── app/
│   ├── ui/
│   │   ├── main_window.py       # 主窗口（顶栏 / 侧边导航 / 四个页面）
│   │   ├── theme.py             # 设计令牌 + QPalette + QSS 生成（浅/深主题）
│   │   ├── icons.py             # 内置 SVG 矢量图标
│   │   ├── onboarding.py        # 首次使用引导
│   │   └── tray.py              # 系统托盘
│   ├── core/                    # 抓取引擎、索引库、EPUB 打包、配置管理
│   └── pixiv/                   # Pixiv API 客户端、正文标记转换
├── tests/smoke_test.py          # 冒烟自检（约 50 项）
└── dist/                        # 打包产物（不入库）
```

## 更新日志

### v1.4.3

- **新增小说排行榜模块**：抓取各榜单前一百名（每页 50 条 × 2 页），按时间序列存入独立 `rank.db`
- **派生指标**：列表直接显示名次变化、收藏日增、连续在榜天数（用 SQL 现算，不落表）
- **正文下载与去重**：上榜作品可顺便下载正文，复用单篇抓取管线（EPUB、目录、过滤、R-18 开关一致）；
  默认只在首次上榜时下载，作品连续霸榜时后续每天对正文发 0 次请求
- **只保留简体中文**：默认只收录简体中文作品（R-18 榜同样处理），可在设置里关闭该过滤
- **自动生成 CSV**：每次抓取后在指定目录自动生成 `排行榜_{榜单}_{日期}.csv`（UTF-8 BOM，
  Excel 可直接打开）；存放目录可自选，同一天重复抓取会覆盖
- **日历式日期**：点日期框弹出日历，已有数据的日期会标出；选过去的日期再点「抓取榜单」即补抓历史
- 抓取完成后自动跳到刚抓到的日期并显示（每日榜是前一天的成绩）
- **任务日志**：页面内有实时日志框，显示抓了哪个榜、多少条、哪篇下载失败，可一键清空
- **补抓历史**：「补抓历史」按钮可往前连续补抓最近 N 天（1~365，可随时中止，天与天之间留 1 秒间隔）；
  已存在的日期会覆盖，取不到数据的日期会单独列出，汇总所有从榜单抓到过的作者，
  显示上榜作品数、累计上榜次数、历史最高名次、最近上榜日期与「是否在抓取名单中」；
  默认**只看未加入名单的作者**，可一键把选中的作者加入名单
- **抓取历史**：页面视图新增「抓取历史」，每一轮抓取的结果都会留存——开始时间、来源
  （手动 / 定时 / 补抓 / 补下载）、榜单、榜单日期、收录条数、**新下载**、跳过、失败、
  过滤条数、耗时与错误原因。重启软件也在，可按列排序，一键导出 CSV 或清空
  （只清流水，不动已抓到的榜单数据；最多保留最近 500 轮）
- **人话日志**：每轮结束还会往数据目录下 `logs\排行榜抓取历史.txt` 追加一行摘要，
  跟程序运行日志 `run.log` 挨着，双击就能看，不需要打开本软件；可在设置里关闭
- 修复：榜单为空时不再只报一句笼统失败，而是区分「当天榜单尚未公布」与
  「条目被遮蔽，可能需要登录 Cookie（R-18 榜无 Cookie 会直接 403）」

### v1.4.2

- **区分「已注销」与「已停用」**：新增 `authors.disabled_reason`（schema v6），抓取时判定的注销写 `deactivated`，
  手动停用写 `manual`，两者分别显示「已注销」与「已停用」；自动复查只捞回注销的，不再误恢复手动停用的作者。
  旧库迁移时对历史停用记录做尽力推断（有停用时间→注销，无→手动），并保留 `.bak`。
- **一键重建 Markdown 索引**：作者页新增「重建索引」按钮，按当前设置重写全部作者的索引文件，
  **不联网、不重新下载作品**；后台线程执行，不卡界面。
- **检索支持插画与状态筛选**：`search_illusts` 此前已实现但界面从未调用，插画/漫画现在可被搜到；
  新增「类型」「状态」两个筛选下拉。
- **失败 / 已删除队列支持单条操作**：新增「重新抓取」（重置为待下载）与「移除记录」（仅删索引记录，本地文件保留）。
- **抓取前自动备份**：每轮抓取前自动导出备份到 `data\backups\`，滚动保留最近 5 份（可调 1–50）。
  **备份明文包含 Cookie**（与手动导出一致），不接受可到「设置 → 系统」关闭。
- **登录失效主动提示**：Cookie 过期导致任务中止时，顶栏徽标显示「Cookie 已失效」、托盘弹出专门通知；
  任务页新增「上次任务」摘要（新增/更新/跳过/失败/远端删除 + 中止原因），切走再回来也能看到。
